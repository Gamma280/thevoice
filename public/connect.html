Connect TheVoice to Claude

Claude reads your profile and audience quotes and saves drafts back to your dashboard.

Easiest way — no key, no files

  1. Copy your server address:

  2. In Claude open Settings → Connectors → Add custom connector (on claude.ai: Customize → Connectors). Name it TheVoice, paste the address, and click Add.
  3. Claude opens a TheVoice page. Log in if asked and click Allow. You’re connected.
  4. Start a chat, click + → Connectors, switch TheVoice on, and ask: “Generate 5 hooks for my app using TheVoice”.
Advanced: connect with a key instead (Claude Desktop config file)

    Use this if the connector above doesn’t work for you. Open Claude Desktop → Settings → Developer → Edit Config, paste this into claude_desktop_config.json, then restart Claude Desktop. It needs Node.js installed.

    The key goes in the env section, not the command line, so it also works on Windows. Treat it like a password.
