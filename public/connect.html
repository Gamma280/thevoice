    Claude’s “Add custom connector” screen only supports OAuth sign-in, so connect with a small bridge instead. Open Claude Desktop → Settings → Developer → Edit Config, paste this into claude_desktop_config.json, then restart Claude Desktop. It needs Node.js installed.
